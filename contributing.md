# Contributing

Open a pull request that adds one line to the right section of `README.md`:

```
- [Name](https://github.com/owner/repo) - What it does, in one sentence.
```

A project belongs on the list when it is open source, installs and runs on hardware you
control, and is either an agent, a tool agents are built with, or a runtime that serves models
to them. Archived or unmaintained projects are removed. Hosted services with a self-host
option count only if the self-hosted path is documented and complete.

Keep descriptions plain and factual. No superlatives, no star counts.
